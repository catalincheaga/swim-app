PASUL 1 / SCRIPTUL

Deschide documentul tău.

În Google Sheets, alege Extensii → Apps Script. Înlocuiește conținutul Code.gs cu scriptul pregătit mai jos și salvează.

Deschide Google Sheet ↗Descarcă scriptul ↓
PASUL 2 / CHEIA DE ACCES

O cheie doar pentru voi.

În Apps Script → Project Settings → Script properties, adaugă proprietatea LANE_TOKEN. Folosește o cheie aleatoare lungă; poți genera una aici, pe dispozitiv. Păstreaz-o pentru setările aplicației.

Cheia generată aici nu se trimite și nu se salvează automat. Nu o publica în GitHub sau în foaia de calcul.

PASUL 3 / CELE TREI FOI

Pregătește jurnalul.

În editorul Apps Script, selectează setupLane și apasă Run. Autorizează scriptul din contul tău Google. Se creează configs, concursuri și date, fără să fie șterse foile existente.

În configs, completează numele înotătorului în coloana valoare, pe rândul cu id = nume. Cluburile și perioadele sunt deja pregătite.

PASUL 4 / CONECTAREA

Publică API-ul și conectează LANE.

  1. În Apps Script: Deploy → New deployment → Web app.
  2. Execute as: Me și Who has access: Anyone. Foaia Google rămâne privată; API-ul permite accesul cu cheia.
  3. Copiază URL-ul care se termină cu /exec.
  4. În LANE → Setări → Google Sheets, salvează URL-ul și cheia LANE_TOKEN.
  5. Apasă Descarcă din Sheet. Dacă ai rezultate locale reale, exportă întâi JSON. După modificări, apasă Trimite în Sheet.

Accesul la API permite citirea și înlocuirea jurnalului oricui deține URL-ul și cheia. Autorizează numai propriul script. Conexiunea reală se verifică după acești pași.
